# Neighborhood Issue Tracker

A MERN stack web application to report and track neighborhood issues like street lights, garbage, water problems in Dulapalli area.

## Features
- Report new issues with location
- View all reported issues
- Mark issues as resolved
- Dulapalli location integrated

## Tech Stack
- Frontend: React.js (Vite)
- Backend: Node.js, Express.js
- Database: MongoDB Compass
- Tools: VS Code, GitHub

## How to Run Locally

### 1. Backend
cd backend
npm install
npm start
-> Runs on http://localhost:5000

### 2. Frontend
cd frontend
npm install
npm run dev
-> Runs on http://localhost:5175
